## The one-sentence truth
The website and on-page SEO/GEO/AEO are now strong and essentially done — same
playbook, same depth as Native Screens. Ranking from here is gated by OFF-SITE
authority: an unverified GBP, zero reviews, and zero citations. Those three
things, not more website work, are what move the needle next.

## What's honestly different from the Native Screens version of this plan
- Native Screens' audit included a **live, by-hand test of 5 real AI-assistant
  queries** from a specific location, which is what actually proved the
  reviews-gate finding. I don't have live web/AI-query access in this
  environment, so GEO-ANALYSIS.md and MAPS-ANALYSIS.md here are structural/
  heuristic audits of what's controllable in code — not a live-tested citation
  rate. Treat the review-count priority as the same proven finding either way;
  it's consistent with every public study on local AI-answer visibility.
- No fabricated Review/aggregateRating schema. Real reviews only, once you have
  them.
- No fabricated pricing. Biohazard cleanup cost varies far more than screen
  enclosures (insurance-dependent, situation-dependent), so pages point to
  /insurance-and-cost/ and "call for an estimate" instead of dollar ranges.
